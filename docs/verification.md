## Ограничения

Браузер использован для чтения и получения настоящих экранов внешних проектов. Полный интерактивный прогон самого лендинга в управляемом предпросмотре не выполнен: штатный навык управления браузером для этой среды недоступен. Обходной сервер для браузерного тестирования не запускался.

Поэтому новые скриншоты клиентских проектов подтверждены; интерактивные сценарии Apollo, браузерная консоль, все адаптивные ширины и результаты Lighthouse не заявляются проверенными. Подробный прогон на реальных устройствах остаётся проверкой перед публичным запуском.

После выбора домена нужно отдельно подтвердить HTTP-коды, редиректы, публичную доступность страниц поисковым роботам и индексацию через поисковые кабинеты.
