# Apollo — студия сайтов
Многостраничный статический сайт на русском языке. 15 основных страниц, два реальных кейса, четыре услуги, команда, процесс и два практических материала. Исходники размещены в GitHub; публикация настроена через GitHub Pages.

## Работа с исходниками
Требуется Node.js 20+. Внешних npm-зависимостей нет.

- npm run build — собрать страницы в dist.
- npm run check — проверить маршруты, локальные файлы, метаданные, разметку и логику брифа.
- npm run preview — обычный локальный сервер для самостоятельного просмотра dist вне управляемой рабочей среды.

Основные файлы:
- src/content.mjs — контакты, стоимость, объём проекта, изображения и FAQ.
- src/studio-content.mjs — услуги, кейсы, руководители и статьи.
- src/render.mjs — общие компоненты и главная.
- src/pages.mjs — внутренние страницы.
- src/seo.mjs — метаданные и Schema.org.
- src/studio.css и src/responsive.css — визуальная система и адаптивность.
- src/studio-app.js — меню, просмотр изображений, фильтр, движение, бриф.
- src/brief.mjs — подготовка текста и mailto.
- scripts/build.mjs — генератор всех страниц.
- scripts/check.mjs — проверки.
- docs/studio-research-2026-10-20.md — исследование и принятые решения.

## Публичный домен и SEO
В src/content.mjs установлен подтверждённый в настройках GitHub Pages домен https://apollo.su и indexable:true. Публичная сборка формирует canonical, sitemap и разрешает индексирование.

При смене публичного HTTPS-домена обновить publicDomain и пересобрать сайт. Сборка добавит канонические адреса, Sitemap 15 основных страниц и разрешение обхода. Нельзя включить индексирование без подтверждённого домена. Уникальные title, description, Open Graph и структурированные данные уже включены. Google/Yandex verification и metrikaId задаются только реальными значениями.

## GitHub Pages
Workflow .github/workflows/pages.yml собирает 15 основных страниц и 404, выполняет проверки и публикует только dist.
scripts/prepare-pages.mjs адаптирует ссылки и ресурсы к адресу проекта /apollo-studio/ или корню собственного домена.
При публикации проверяются главная и все опубликованные файлы: их содержимое должно совпасть с результатом сборки.
Для активации в Settings → Pages нужно выбрать Source: GitHub Actions. Настройка Pages требует прав администратора.
Домен apollo.su подтверждён текущими настройками GitHub Pages. В src/content.mjs установлены publicDomain:'https://apollo.su' и indexable:true; после изменения DNS GitHub завершит настройку HTTPS.
