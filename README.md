# Apollo — сайты для промышленного и технического бизнеса

Статический сайт: 15 содержательных страниц, два кейса, четыре услуги, команда, процесс и два практических руководства. Публичный адрес: https://apollo.su. Демо: https://apollo-industrial.mishanka2008.chatgpt.site.

## Разработка

Требуется Node.js 20+. Внешних npm-зависимостей нет.

```sh
npm run build
npm run check
```

Публичная сборка использует `https://apollo.su`, canonical и sitemap. Для приватного демо:

```sh
APOLLO_PREVIEW=1 npm run build
APOLLO_PREVIEW=1 npm run check
```

Этот режим запрещает индексацию и удаляет публичный sitemap. Управляемое превью запускается через Sites; `npm run preview` предназначен для обычного локального просмотра вне управляемой среды.

## Исходники

- `src/content.mjs` — контакты, цена, объём, этапы, FAQ и изображения.
- `src/studio-content.mjs` — руководители, услуги, кейсы, статьи, примеры и таблицы.
- `src/render.mjs`, `src/pages.mjs` — компоненты, главная и внутренние страницы.
- `src/studio.css`, `src/responsive.css` — визуальная система и адаптивность.
- `src/seo.mjs` — метаданные и Schema.org.
- `src/studio-app.js`, `src/brief.mjs` — меню, просмотр изображений, фильтры и составление обращения.
- `scripts/build.mjs`, `scripts/check.mjs` — генератор и проверки.
- `docs/content-research-2026-10-22.md` — источники, редакционные решения и границы подтверждённых утверждений.

## Публикация

Sites хранит отдельную приватную демоверсию. GitHub Pages разворачивает публичную сборку из `main` через workflow `.github/workflows/pages.yml`; `scripts/prepare-pages.mjs` подготавливает домен и пути. Workflow проверяет сборку и опубликованные файлы. Эти два файла относятся к GitHub-репозиторию и не требуются для сборки Sites.
