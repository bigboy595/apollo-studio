# Apollo — цифровые решения, маркетинг и дизайн

Публичный сайт студии: https://apollo.su. Публикация через GitHub Pages из ветки `main`.

Главная — фиксированный экран: заголовок, навигация и кнопка обсуждения доступны сразу. Полное 3D-вступление запускается кнопкой «Смотреть интро»: последовательное появление трёх столбиков Apollo, индивидуальная инерция, объезд камеры, подвижные студийные блики, цветное объёмное свечение и упругий импульс с переходом к сетке и заголовку. Рендерер и покадровые атласы загружаются только по запросу. Есть пауза, пропуск, повтор и поддержка reduced motion. Для браузеров без WebGL предусмотрен покадровый 3D-резерв.

Три направления: цифровые решения, маркетинг и дизайн, сайты для бизнеса. В каталоге опубликован только Apollo Track со встроенной интерактивной демоверсией клиента и менеджера. Страница продукта описывает пилот, внедрение, интеграции, модель стоимости и ограничения. 44 услуги сохранены; для контекстной рекламы, фирменного стиля и коммерческих предложений добавлены самостоятельные страницы. Всего 32 содержательные страницы и 404.

## Сборка и проверка

Node.js 20+; npm-зависимости не требуются.

```sh
npm run build
npm run check
PAGES_SITE_URL=https://apollo.su node scripts/prepare-pages.mjs
```

GitHub Actions выполняет сборку, проверки, подготовку путей, публикацию и сверку выложенных файлов. Исходники находятся в `src`, статическая сборка и локальные ресурсы — в `dist`. Для внутреннего просмотра без индексации используйте `APOLLO_PREVIEW=1 npm run build` и `APOLLO_PREVIEW=1 npm run check`.

Форма брифа локально готовит письмо; автоматически ничего не отправляет. Технодемка Track использует тестовые данные и браузерное хранилище. Авторизация, CRM и доставка уведомлений для рабочего продукта подключаются отдельно.

Демонстрационный интерфейс `/demos/track/` содержит `noindex,follow` и исключён из sitemap; `robots.txt` разрешает обход, чтобы поисковик мог прочитать запрет индексации. Посадочная `/solutions/track/` открыта для индексации. JSON-LD формируется из тех же данных, что и видимое содержание: Organization, WebSite, WebPage, Service, BreadcrumbList, ItemList, FAQPage и существующие статьи/кейсы. Проверки сопоставляют FAQ и списки с HTML. Изменения описаны в `docs/seo-fixes-2026-11-09.md`.

3D-сцена и таймлайн: `src/experience/intro.js`, `logo-renderer.js`, `motion.js`. Резервные атласы: `dist/assets/intro/film`. Повторное 3D-запекание — `python scripts/render/render-film.py` с Pillow и Mesa EGL/OpenGL; посетителям сайта эти зависимости не нужны.
